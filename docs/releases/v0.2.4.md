## 中文

### 升级要点（TL;DR）

- **无破坏性**：宿主窗口不变（`>=0.1.7-alpha.1 <0.2.0`）；journal 格式、任务夹契约、`teamflow_*` 工具参数全部向后兼容。
- **升完重启 `dsh --profile web` 生效**。
- 纯工程基建：确立代码格式单一仲裁者（`@stylistic/indent`，不引入 Prettier）、行长上限对齐宿主收严到 140、加 lefthook 预提交钩子自动修复 staged 文件、风格门禁改走宿主同款 `@stylistic`（oxlint jsPlugins）。

### 为什么做这套基建：三种漂移

本版的每一组改动都来自「风格不收敛」导致的实际摩擦：

1. **格式无单一权威**：此前缩进靠 `@stylistic/indent` 之外的手工约定，AI 生成代码与贡献者提交在缩进/分行上易漂移；Prettier 与 `@stylistic/indent` 在 JSX 缩进上互斥，不能混用。
2. **行长无统一上限**：各文件行宽不一，diff 噪声大，跨仓（与宿主 dsh）协作时认知成本高。
3. **合规靠事后门禁**：只有 oxlint 的 warning 门禁，没有「提交即修」的钩子，不合规范的代码会先溜进历史再被修。

### 本次变更

**① 代码格式单一仲裁者（规范 `docs/anchors/code-style.md`）**

- 确立 `@stylistic/indent` 为唯一格式权威，明确**不引入 Prettier**（两者在 JSX 缩进上互斥）。
- 规范文件落地两条纪律：① 规则准入要么可自动修、要么存量清零；② 源码断言锁（smoke 正则）**只锁内容不锁排版**（跨行分隔符写 `\s*`、容忍尾逗号 `,?`），避免每次折行都需改断言。

**② max-len 收严到 140（对齐宿主）**

- 全仓 53 处超长行**手工折行**（不改语义）；3 条长正则（失败分类 / 内容失败 / 安装块）拆成语义分组数组 `new RegExp([...].join('|'), 'i')`，并对每个拆分做**等价性校验**（`.source` 必须等于原始字面量），`disable` 计数归零——不靠 `eslint-disable` 逃避。

**③ lefthook 预提交钩子（贡献者提交即合规）**

- `pnpm format`（两遍 `--fix`）+ `git diff --cached --check` 空白检查，`stage_fixed: true`；`pnpm-workspace.yaml` 加 `allowBuilds: lefthook: true`，`package.json` 加 `postinstall` 自动安装钩子。

**④ 风格门禁改走宿主同款 `@stylistic`（oxlint jsPlugins）**

- oxlint `jsPlugins` 加载 `@stylistic/eslint-plugin`，**103 规则、0 warning 门禁**；因 jsPlugins 仍 alpha 不随 semver，`oxlint` 锁精确版本 `1.85.0`。
- 三层缩进兜底：`@stylistic/indent` 规则 + `pnpm format` 自动修 + `.editorconfig` 编辑器侧约定，兜住 lint 管不到的缩进。

### 已知边界与后续

- 折行仍靠手工：max-len 目前「只报警不自动修」的自动化未做，已在 `docs/TODO.md` 留痕（低优先）。

## English

### Upgrade notes (TL;DR)

- **No breaking changes**: host window unchanged (`>=0.1.7-alpha.1 <0.2.0`); journal format, task-folder contract and `teamflow_*` tool arguments are all backward compatible.
- **Restart `dsh --profile web` after upgrading**.
- Pure engineering hygiene: a single formatting authority (`@stylistic/indent`, no Prettier), line-length cap tightened to 140 to match the host, a lefthook pre-commit hook that auto-fixes staged files, and the lint gate now using the host's own `@stylistic` (oxlint jsPlugins).

### Why this hygiene pass: three sources of drift

Every change group here comes from friction caused by non-convergent style:

1. **No single formatting authority**: indentation relied on hand-written conventions outside `@stylistic/indent`; AI-generated code and contributor commits drifted on indentation/wrapping. Prettier and `@stylistic/indent` are mutually exclusive on JSX indentation and cannot be mixed.
2. **No unified line-length cap**: inconsistent line widths created diff noise and high cognitive cost when collaborating across repos (with the host dsh).
3. **Compliance was post-hoc only**: there was an oxlint warning gate but no "fix on commit" hook, so non-conforming code entered history first and got fixed later.

### Changes

**① Single formatting authority (spec `docs/anchors/code-style.md`)**

- `@stylistic/indent` is the sole formatting authority; Prettier is explicitly **not** introduced (the two are mutually exclusive on JSX indentation).
- The spec pins two disciplines: ① a rule is admitted only if it is auto-fixable or its existing violations are cleared; ② source-assertion locks (smoke regexes) **lock content, not formatting** (cross-line separators use `\s*`, trailing commas tolerate `,?`), so every wrap does not require rewriting an assertion.

**② Line-length cap tightened to 140 (host-aligned)**

- All 53 over-long lines across the repo were **hand-wrapped** (semantics untouched); 3 long regexes (external-failure / content-failure / install-block) were split into semantic grouped arrays `new RegExp([...].join('|'), 'i')`, each split **equivalence-checked** (`.source` must equal the original literal). The `disable` count dropped to zero — no escape via `eslint-disable`.

**③ lefthook pre-commit hook (contributor-commits-compliant)**

- `pnpm format` (two `--fix` passes) + `git diff --cached --check` whitespace check, `stage_fixed: true`; `pnpm-workspace.yaml` gains `allowBuilds: lefthook: true`; `package.json` gains a `postinstall` that installs the hook automatically.

**④ Lint gate now uses the host's own `@stylistic` (oxlint jsPlugins)**

- oxlint `jsPlugins` loads `@stylistic/eslint-plugin` at **103 rules with a 0-warning gate**; because jsPlugins is still alpha and not semver-tracked, `oxlint` is pinned to exact `1.85.0`.
- Three-layer indentation backstop: the `@stylistic/indent` rule + `pnpm format` auto-fix + `.editorconfig` editor-side convention, covering indentation that lint alone cannot reach.

### Known boundaries and follow-ups

- Wrapping is still manual: max-len currently "warns but does not auto-fix"; that automation is filed in `docs/TODO.md` (low priority).
- smoke source-assertion locks are now explicitly a **backstop** (content-only, not formatting); the primary gate is oxlint + lefthook.
- Metering stops at **token volume**: cost "from volume to money" was decided against (per-model prices differ, prices change, and "token × unit price" does not hold under plan/subscription billing).
- Next version **v0.2.5 = orchestration testability**: after splitting pipeline into qa (state machine) / dev (waves) / acceptance, add end-to-end orchestration tests with fake subagents — still the largest test gap.
- `engines.dsh` window stays `>=0.1.7-alpha.1 <0.2.0` (semver does not cover prereleases; documented against official-release boundaries).
