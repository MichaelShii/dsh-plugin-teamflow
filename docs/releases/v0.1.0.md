## 中文

### 它能做什么

把需求自动跑成完整研发流水线：

需求 → PRD →（设计）→（架构/脚手架）→ 技术方案 → 并行开发 → QA → 验收
，配套 backlog 持久化、断点续跑、完成自动汇报、🏭 团队工作台 Web tab。

### 核心能力

- **多 Agent 流水线 + 档位**：`full` / `medium` / `lite` / `tech` / `patch` 五档阶段集（ADR-0004）；`lite` 实测较完整 7 段省 ~64% 时间、~88% token。
- **防假交付**：实质校验（拒绝词 + 长度下限）+ 单阶段 60k token 熔断 + 上下文耗尽不重试 + 产品级并发锁 + 内存裁剪。
- **断点续跑**：自研 journal（不依赖 LangGraph），进程崩溃自动标记 `interrupted`，从首个未完成阶段续跑复用产物全文。
- **backlog 持久化**：按工作区隔离落 `$DSH_HOME/teamflow/<workspace>/backlog/`，跨重启不丢。
- **真实 token 计量（官方口径）**：输入未命中/命中/写缓存/输出 + 调用数 + 缓存命中率，工作台卡片与完成汇报同款口径。
- **QA 打回修复有界闭环（ADR-0007）**：P0–P2 缺陷打回开发修复 → 复验，上限转 `needs-human`，不静默进验收。
- **任务夹文档制（ADR-0008）**：每需求自包含任务夹，消除双归档 / memory 堆积。
- **🏭 团队工作台（Web tab）**：阶段泳道 + 拖拽看板（HTML5 DnD 零依赖）+ 成本中心 + 人工介入中心。

### 安装

```bash
dsh plugin --profile web add dsh-plugin-teamflow
```

安装后重启 `dsh --profile web`，模型侧出现 11 个 `teamflow_*` 工具，会话头部出现「🏭 团队工作台」tab。

## English

### What it does

Turns a requirement into a complete R&D pipeline automatically:

Requirement → PRD → (Design) → (Architecture/Scaffold) → Tech Spec → Parallel Dev → QA → Acceptance
, with backlog persistence, resume-from-checkpoint, auto completion report, and a 🏭 Team Workspace web tab.

### Core capabilities

- **Multi-agent pipeline + tiers**: `full` / `medium` / `lite` / `tech` / `patch` five stage-set policies (ADR-0004); `lite` measured ~64% time / ~88% token savings vs the full 7-stage run.
- **Anti-fake-delivery**: substantive validation (rejection phrases + length floor) + 60k token circuit breaker per stage + no retry on context-exhaustion + product-level concurrency lock + memory trimming.
- **Resume from checkpoint**: self-hosted journal (no LangGraph); crash auto-marked `interrupted`; resumes from the first unfinished stage reusing full stage outputs.
- **Backlog persistence**: workspace-isolated under `$DSH_HOME/teamflow/<workspace>/backlog/`, survives restarts.
- **Real token metering (official semantics)**: cache-miss / cache-hit / write-cache / output + call count + cache hit rate, same basis across workspace cards and completion report.
- **QA rework bounded loop (ADR-0007)**: P0–P2 defects bounce back to dev → re-verify; cap escalates to `needs-human`; never silently passes into acceptance.
- **Task-folder docs (ADR-0008)**: per-requirement self-contained folder, eliminates double-archive / memory bloat.
- **🏭 Team Workspace (Web tab)**: stage swimlanes + drag-drop kanban (HTML5 DnD, zero-dep) + cost center + human-intervention center.

### Install

```bash
dsh plugin --profile web add dsh-plugin-teamflow
```

Restart `dsh --profile web` after install; 11 `teamflow_*` tools appear and the 🏭 Team Workspace tab shows up in the session header.
