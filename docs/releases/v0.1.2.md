## 中文

### 本次变更

- **提示词指令层英文化（方案 A）**：12 个阶段 prompt / token 卫生 / 一次成型纪律 / 工具描述改英文指令；**输出契约保持中文**（PRD 头部 `基线依赖`/`取代` 声明、QA 缺陷表、`未发现缺陷`、验收结论符号）——解析器与中文产品文档锚点零改动
- **Backlog 卡片 → 流水线视图跳转**：卡片/详情抽屉「▶ 流水线」直达该需求 run 的流水线图（host `backlog` 附带 `runId` 映射）
- **详情抽屉长文本折叠**：概览 / 需求原文默认预览几行，可展开/收起，不再铺满
- **断点重跑语义修正**：阶段全 done 的 failed/cancelled 不再显示续跑按钮（阶段全绿 ≠ run 成功，如「需求与现状不符」拦截单），host 硬拒绝兜底；按钮/pill/chip 补 runId 全名可溯
- **架构蓝图提取回退**：模型把蓝图写进任务夹 `TECHNICAL.md`（而非回复输出）时，M2 拆卡不再退化为单任务整体开发
- **`meta.json` 静态标识卡**：废弃终态回写（status/endedAt 权威在 journal），根治「提交后再脏」与快照过时
- **开源发布元数据**：`keywords`/`homepage`/`bugs`；`react` 移入 peerDependencies（宿主注入）；`peerDependenciesMeta` 防私有包 ERESOLVE；CI 扩展 `main` + `release-*` 分支；sourcemap 关闭（npm 包 -58%）；新增 SECURITY.md / CONTRIBUTING.md；README 双语同步修正

## English

### Changes

- **Prompt instruction layer in English (Plan A)**: 12 stage prompts / token hygiene / one-shot discipline / tool descriptions now English; **output contracts stay Chinese** (PRD `基线依赖`/`取代` headers, QA defect table, `未发现缺陷`, acceptance verdict symbols) — parsers and Chinese product-doc anchors untouched
- **Backlog card → pipeline view jump**: "▶ pipeline" button on cards / detail drawer jumps to that requirement's run (host `backlog` now carries a `runId` map)
- **Foldable long text in detail drawer**: overview / requirement text preview a few lines with expand/collapse
- **Resume semantics fixed**: failed/cancelled runs whose stages are all done no longer show the resume button (all-green stages ≠ run success, e.g. "requirement not applicable" intercepts); host hard-refuses; runId fully traceable on button/pill/chips
- **Blueprint extraction fallback**: when the model writes the blueprint into the task-folder `TECHNICAL.md` (instead of the reply), M2 task splitting no longer degrades to a single whole-dev task
- **`meta.json` static identity card**: terminal-state write-back removed (status/endedAt authoritative in journal) — fixes "dirty again after commit" and stale snapshots
- **Open-source release metadata**: `keywords`/`homepage`/`bugs`; `react` moved to peerDependencies (host-injected); `peerDependenciesMeta` to avoid ERESOLVE on private packages; CI extended to `main` + `release-*`; sourcemaps off (npm package -58%); added SECURITY.md / CONTRIBUTING.md; bilingual README fixes
