# TeamFlow v0.1.6

[中文](#zh) | [English](#en)

Release — a hardening release: token metering re-adapted to the host's session v2 (usage was silently blank on pipeline cards), resume rebuilt as a proper state machine (only incomplete tasks re-run), QA/acceptance reports are now file-only deliverables with a strict verdict-line contract, dev replies carry auditable verification evidence, and a new eval layer (L1 contract tests + L2 replay-corpus conformance) makes prompt/injection changes measurable with zero LLM cost.

## 中文

### 本次变更

**新增**
- **评测层 L1+L2（prompt/注入改动收益评测）**：L1 行为级契约测试——直接调用 prompt 工厂断言 29 条产出锚点，分 `[HOST-ENFORCED]`（host 真实强制：单轨产物/验收结论行）/ `[policy]`（自律+轻提醒）/ `[structural]` 三级，改 prompt 一眼看出断了哪条、丢哪级保障；L2 回放语料一致性门禁——冻结真实形状的 QA-REPORT / ACCEPTANCE / dev 回复 / 架构蓝图产物，喂宿主真实解析器做 golden corpus 回归（零 LLM 成本）。语料只增不改，防评测集过拟合
- **dev/qaFix 验证证据块**：开发回复末尾强制「[Verification evidence]」块（命令 + 退出码 + 断言计数 + 失败行引用，或显式 N/A），host 提取存证、阶段详情抽屉可见、可与 `logs/teamflow/<runId>/` 命令日志交叉核对——开发阶段从「单方宣称全绿」升级为「可审计的具体自述」
- **代码级英文化（为 UI i18n 铺路）**：代码判断/命名全英文（阶段键 `prd/design/scaffold/tech/dev/qa/acceptance`、任务结构化键 `taskKey`），中文只留展示层；存量 journal/backlog 提供迁移脚本 `scripts/migrate-phase-en.mjs`

**改进**
- **resume 断点续跑状态机化**：两级状态（大阶段 + 子图任务）聚合判定——任务有 done 尝试即成功（历史失败尝试不算失败）；resume 只补跑「聚合后未成功」任务、复用已完成产物，不再读 backlog 子卡（残留失败卡不再污染判定）；dev 部分成功时起点精确回开发补跑未完成项，全 done 时正确落在 QA/验收
- **输出单轨制**：QA/验收的完整报告只写在任务夹文件（`QA-REPORT.md` / `ACCEPTANCE.md`），子代理回复仅摘要+路径——host 直接导入文件（缺陷表/补测清单/核对表），文件缺失即停线人工，杜绝「回复与文件不一致」的双轨假交付
- **验收结论契约强度**：验收报告结论行必须为字面量模板且为文件最后一行（`验收结论：✅ 通过 ／ ⚠️ 有条件通过 ／ ❌ 不通过 ／ 📝 需求不适用`）；无结论行/空结论行/待定 → 需人工确认（不再默认通过，防质量门禁漏报）
- **prompt 约束分级**：区分 `[HOST-ENFORCED]`（host 真实强制，标注必须描述真实后果）与 `[policy]`（自律 + guard warn/轻提醒，标注真实机制）；prompt 内不再自称 hard constraint（措辞硬与 enforcement 脱节会训练模型脱敏）
- **重试诊断包**：重试时把上次失败详情（outcome / 护栏原因 / 拒绝词命中点 / 产出尾部 1k）附进 prompt——盲试 → 带因重试；stalled（挂死/空转）不再自动重试，引导 resume

**修复**
- **token 计量适配宿主 session v2**：宿主新版会话已无 `events` 属性，计量读不到 → 流水线卡与图卡无「TOKEN · 官方口径」。修复：事件多源回退（`snapshotEvents()`/`ownEvents()`）+ usage 双路径（含 `data.stream` 内嵌 usage chunk），新 run 计量恢复
- **护栏挂死误杀**：QA 子代理正常干活却被判「10 分钟无事件」（宿主事件视图失明）——事件读取多源回退 + agent 活动守卫（非 idle 且已动手即不中止），stalled 触发前记录各源视图长度供排查
- **任务卡 token 统计并发错位**：子卡 usage 按 `withRetry` 返回的 stage 引用直写（并发下不再错位/超计）
- **存量迁移脚本 taskKey 误判**：合法中文括号结尾的任务键不再被当作历史残留（此前幂等无损但计数虚高、无谓重写）
- **验收空结论行/裸否定词漏报**：四档词白名单校验覆盖 accepted 分支（前缀残留的空行/裸「不通过」不再漏回 accepted）
- **AGENTS.md 注入面瘦身 64%**（devlog/TODO 迁出，避免 token 常驻与决策污染）

## English

### Changes

**New**
- **Eval layer L1+L2 (measuring prompt/injection changes)**: L1 behavioral contract tests invoke the prompt factories and assert 29 output anchors, tiered `[HOST-ENFORCED]` / `[policy]` / `[structural]` — editing a prompt shows at a glance which contract broke and which guarantee tier it carried; L2 replay-corpus conformance freezes realistic QA-REPORT / ACCEPTANCE / dev-reply / architecture-blueprint artifacts and runs them through the real host parsers as a golden-corpus gate (zero LLM cost). Corpus files are append-only to avoid eval overfitting
- **Verification-evidence block for dev/qaFix replies**: a mandatory `[Verification evidence]` block (exact command → exit code, passed/failed asserts with file:line, or explicit N/A) is extracted and stored by the host, visible in the stage-detail drawer and cross-checkable against `logs/teamflow/<runId>/` command logs — dev claims upgraded from "self-reported green" to auditable specifics
- **Code-level English-ization (paving the way for UI i18n)**: code keys/phase identifiers are now English (`prd/design/scaffold/tech/dev/qa/acceptance`, structured task key `taskKey`); Chinese remains only in display labels; a migration script handles legacy journals/backlog

**Improvements**
- **resume rebuilt as a state machine**: two-level aggregation (macro stage + sub-graph tasks) — a task with any `done` attempt counts as successful; resume re-runs only tasks that are not yet successful and reuses finished artifacts, no longer reading backlog subtask cards (stale failed cards can no longer pollute the decision); partially-completed dev resumes precisely into dev, fully-completed dev lands correctly on QA/acceptance
- **Single-track file deliverables**: QA/acceptance write their full reports only to task-folder files (`QA-REPORT.md` / `ACCEPTANCE.md`); subagent replies carry just a summary + path — the host imports the files directly (defect table / manual-test list / check table); a missing file hard-fails to manual review, eliminating reply-vs-file divergence
- **Acceptance verdict-line contract hardened**: the report's final line must be a literal verdict (`验收结论：✅ 通过 ／ ⚠️ 有条件通过 ／ ❌ 不通过 ／ 📝 需求不适用`); missing / empty / undecided conclusion lines now route to needs-human instead of defaulting to accepted
- **Prompt constraint tiering**: `[HOST-ENFORCED]` (real host enforcement, must describe the real consequence) vs `[policy]` (self-discipline + guard warn/light reminder, must state the real mechanism); prompts no longer call themselves "hard constraints"
- **Retry diagnostics**: retries now embed the last failure's details (outcome / guard reason / refusal-phrase hit / 1k output tail); stalled runs no longer auto-retry and are steered to resume

**Fixes**
- **Token metering adapted to host session v2**: the host's new session API dropped the `events` property, so metering read nothing and pipeline/task cards showed no official token usage. Fixed with multi-source event fallback (`snapshotEvents()`/`ownEvents()`) plus dual-path usage extraction (including usage chunks embedded in `data.stream`) — new runs meter correctly again
- **Guard false "hung" kills**: QA subagents busy at work were flagged "no events for 10 minutes" (a stale host event view). Fixed with multi-source event fallback + an agent-busy guard (non-idle and has acted ⇒ do not abort), with a view-length diagnostic before any stall fires
- **Concurrent task-token mis-attribution**: subtask usage is now written against the stage reference returned by `withRetry` (no more off-by-one or over-counting under concurrency)
- **Migration script taskKey false positives**: task keys legitimately ending in Chinese parentheses are no longer treated as residue (previously idempotent but inflated counts and rewrote files needlessly)
- **Acceptance empty/negated-verdict leaks**: four-tier word whitelist now also guards the accepted branch (a residual-prefix empty line or a bare "不通过" no longer leaks back to accepted)
- **AGENTS.md injection slimmed 64%** (devlog/TODO moved out — less resident-token churn and decision pollution)
