## English

### What's changed

- **Lean npm package**: `files` allowlist narrowed to `lib` / `cordis.patch.yml` / `README.md`; `AGENTS.md` and `docs/adr` are no longer shipped (dev docs live in the GitHub repo).
- **`repository` field**: the npm page now links to the GitHub repo and relative README links resolve.
- **Bilingual README**: new `README.en.md` with a `中文 | English` toggle at the top.

### Install

```bash
dsh plugin --profile web add dsh-plugin-teamflow
```

Functionality is identical to v0.1.0 (5-tier pipeline / resume / backlog / official token metering / 🏭 Team Workspace).

- Usage & architecture: [README.md](./README.md)
- License: MIT — [LICENSE](./LICENSE)
