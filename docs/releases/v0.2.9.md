## 中文

### ⬆️ 升级要点

- **先升宿主，再升插件**。本版把 `engines.dsh` 收窄为 `>=0.2.1-alpha.2 <0.3.0`——**宿主低于该版本会被宿主直接
  跳过本插件（`skippedBundles`，工作台不可用）**。这是宿主在 alpha.2 删除旧接口后的必然结果，不是可绕过的。
- 升级命令见 README；升完**重启** `dsh --profile web`（桌面版重启桌面应用）。
- 之后的新版本会由插件自己提示（v0.2.8 引入的更新提示），无需再手动查。

### ① 破坏性：适配宿主 alpha.2 的 subagent API（issue #20）

宿主 `dsh-v0.2.1-alpha.2`（提交 `3d852a1cea`）**删除**了扁平入口 `subagents.start(name, request)`，唯一入口改为
`startActivation(spec)`。

- **不做旧版兼容、不写 shim**：以 `engines.dsh` 当门禁。⚠️ 顺带订正两条**旧结论**——`engines.dsh` 是**宿主强校验**
  的（旧 README 写「宿主不校验」是错的）；alpha.2 起 **one-shot 也占 `maxActiveSubagents` 池**（默认 8）。
- **计量句柄必须在「启动窗口内」取**：宿主对本地子级 **idle 即 close**，而 `activation.result` 要等 handle cleanup
  **之后**才 settle ⇒ 原来的「lazy getter」读 token usage 时句柄早已注销（实锤某个 run **21/21 阶段 usage 全空、
  静默数小时**，run 还照报 completed）。现在改为 `startActivation` 返回**那一刻**取活 Agent 塞进句柄；再取不到就以
  `diag.usageMissing` 每 run 一条 warn 显式上报（空值必须可见）。
- **跳子代理会话的地址 `mode` 传 `'unknown'`**：本插件的阶段子代理在 alpha.2 起一律记 `continuable`，写死 `'one-shot'`
  会被宿主判 `subagent/unauthorized`（实机点「跳转子代理会话」即失败）。`'unknown'` 是宿主钦定的浏览语义，不是猜。

## English

### ⬆️ Upgrade notes

- **Upgrade the host first, then this plugin.** `engines.dsh` is now `>=0.2.1-alpha.2 <0.3.0`. On an older host the
  plugin is **skipped by the host** (`skippedBundles`, workbench unavailable). This is forced by the host deleting the
  old subagent entry in alpha.2 — there is no workaround.
- After upgrading, **restart** `dsh --profile web` (restart the desktop app on desktop).
- Future versions will announce themselves (the update notice introduced in v0.2.8).

### ① Breaking: adapt to host alpha.2 subagent API (issue #20)

Host `dsh-v0.2.1-alpha.2` (commit `3d852a1cea`) **removed** the flat entry `subagents.start(name, request)`; the only
entry point is now `startActivation(spec)`.

- **No backward compatibility, no shim** — the `engines.dsh` range is the gate. Two earlier conclusions were also
  corrected: `engines.dsh` **is** host-enforced (the old README claim that it is not was wrong), and since alpha.2
  **one-shot agents also occupy the `maxActiveSubagents` pool** (default 8).
- **Metering handles must be taken inside the startup window.** The host closes a local child as soon as it goes idle,
  while `activation.result` settles only **after** handle cleanup — so the previous lazy getter read token usage after
  the handle was already unregistered (one real run had **all 21/21 stages with empty usage, silently, for hours**).
  Handles are now captured the instant `startActivation` returns; missing values raise a per-run `diag.usageMissing` warn.
- **Subagent-session address `mode` is now `'unknown'`.** Stage subagents are recorded as `continuable` since alpha.2, so
  a hard-coded `'one-shot'` is rejected as `subagent/unauthorized`. `'unknown'` is the host's own browsing semantics.

### ② Fixes found on real machines

| # | Symptom (observed on a real machine) | Fix |
|---|---|---|
| 1 | Whole run produced **English artifacts in a Chinese environment** | Client locale push is now a **bounded retry** (stop on success / 2s reschedule / max 8 / generation guard / quiet dispose); host adds a three-state `localeSource()` and warns visibly when a new run falls back |
| 2 | **Confirm sheet carried the previous run's content** | `state.json` accumulates across runs; the confirm sheet now reads a **run-level snapshot** (`journal.prdSnapshot`) and honestly says "not captured" instead of showing stale values |
| 3 | A wrong tool argument was classified as **environment unavailable** and hard-stopped | The argument-failure exemption now matches the **parse-layer prefix** class (`invalid arguments:`), not just three fs-tool messages |
| 4 | **Fixed** defects in a QA re-verification table counted as open blockers → "never converged" → **acceptance skipped, run wrongly downgraded to needs-human** | The status/conclusion column is now honored (rows explicitly marked closed are skipped); frozen corpus + loop-level gate added |
| 5 | "File is the artifact" only checked existence/length → upstream could write downstream artifacts | **Freshness fingerprint** (size:mtimeMs captured at stage start) |
| 6 | All open defect cards showed "unclaimed" while two very different reasons were indistinguishable | Cards/detail pane now show a "why still open" line |
